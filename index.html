A. Profil Saya

Halo nama saya Fajar Arya Pratama. Saya mahasiswa aktif program Studi Informasi di Fakultas Ilmu Komputer. Saya memiliki ketertarikan pada bidang fotografi, pengembangan web, analis sistem informasi. Saya senang belajar hal baru, karena dapat membuat saya menjadi lebih pintar dan dapat mengemukakan ide-ide yang dapat saya kembangkan di masa depan. Selain itu saya juga tertarik untuk mengembangkan kemampuan dalam pemrograman dan pembuatan sistem yang mudah digunakan. Selama menjadi mahasiswa, saya terus berusaha meningkatkan pengetahuan dan keterampilan melalui tugas dan projek perkuliahan.

Selain itu saya juga memiliki hobi travelling, olaharaga dan fotografi. Terutama travelling, karena frekuensi perjalanan saya cukup jauh temaan-teman saya terkadang sering bertanya kepada saya tentang rute termurah menuju tujuan tertentu. Selain itu, saya adalah orang yang dapat menemukan ide/solusi ketika ada masalah atau konflik yang sedang berlangsung, skill itu saya dapatkan ketika saya berada di Organisasi MPK saat SMA.

Halaman web ini dibuat menggunakan HTML5 murni tanpa menggunakan CSS untuk memenuhi intruksi pembuatan struktur dasar web. Dalam pembuatan halaman ini, saya menggunakan berbagai tag HTML untuk menyusun struktur dan menampilkan informasi. Saya juga mempelajari fungsi dari setiap tag agar dapat digunakan sesuai dengan kebutuhan halaman web. Pembuatan halaman ini menjadi salah satu latihan memahami dasar-dasar pengembangan web. Dengan latihan ini, saya berharap dapat memahami HTML dan dengan lebih baik dan mampu menggunakannya dalam membuat halaman web yang lebih kompleks.
